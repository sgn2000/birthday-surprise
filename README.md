# Birthday Surprise 🎂

Mobile-first birthday countdown landing page for GitHub Pages.

## GitHub Pages URL

If this repository is named `birthday-surprise` under `sgn2000`, the project site will be:

`https://sgn2000.github.io/birthday-surprise/`

## Files

- `index.html` — page structure
- `style.css` — mobile-first design
- `script.js` — countdown timer

## Date

The countdown currently targets **1 December 2026 at 12:00 AM IST**.

No external libraries are required.
